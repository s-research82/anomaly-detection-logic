Module 1: Integrity Check (IC) / 1. modul: Integritás-ellenőrzés

1.1 Fundamental Formula / Alapképlet
If Authority < Liability, then Integrity = FALSE.
Ha a hatáskör < felelősség, akkor az integritás = HAMIS.

1.2 Input Validation / Bemeneti validáció
• Data Completeness (DC): Are all required variables present? / Minden szükséges változó rendelkezésre áll?
• Data Freshness (DF): Is the timestamp within the acceptable threshold? / Az időbélyeg az elfogadható küszöbértéken belül van?

1.3 System Response / Rendszerválasz
• If Integrity = FALSE, the process must be aborted. All subsequent analysis is considered invalid.
• Ha az Integritás = HAMIS, a folyamatot meg kell szakítani. Minden további elemzés érvénytelennek minősül.
